Skill 雷达｜2026年11月27日

发表于 2026-11-27 10:20 更新于 2026-11-27 10:20 分类于 Skill 雷达

设计库里的组件怎样对应代码？更换代码助手前，哪些权限和配置得手工核对？本期从这两项团队交接工作出发，也介绍云端生图与短视频分镜的选型边界。常青回顾则看两种便于交给别人复核的产物：可直接分享的 React 单文件原型，以及只写草稿、不自动发帖的 Reddit 回复流程。

Skill 概览

下表展示本期候选，收录不等于推荐；详细介绍见后文。

序号 Skill 功能简介 主要应用场景
1 reddit-automation 筛选真正求助的 Reddit 帖子，并起草待人工审核的短回复。 从指定社区寻找真实需求；审核利益相关的技术回复
2 frontend-design 先确立页面视觉方向，再按题材、文案和可访问性要求实现。 产品落地页改版；数据面板视觉层级梳理
3 twitter-automation 通过第三方 CLI 读取 X 内容，并操作已授权账号的帖子与互动。 读取公开帖以备人工审稿；已授权团队账号的内容管理
4 webapp-testing 用 Python Playwright 检查本地页面交互，并记录截图和控制台日志。 前端表单回归检查；复核间歇性界面报错
5 ui-design 把界面想法先放进可编辑的 UX Pilot 画布，再按选定方案实现。 改版前比较两份界面方案；把已有 HTML 原型交给设计方评审
6 og-images 用真实界面截图排版分享卡片，并检查成图的尺寸、对比度与裁切。 更新产品的链接预览图；准备发布图库与社交页眉
7 notion-research-documentation 汇总多个 Notion 页面，在带来源引用的简报、对比或报告中整理发现。 将内部选型资料整理成对比文档；从项目页提炼决策背景
8 website-builder 在 DoAny 上创建或更新托管网站，先交预览再由所有者决定是否上线。 从业务简介做小企业首页预览；查看已有站点的待发布变更
9 ai-video-generation 按文本、图片或参考素材选择云端模型，生成并组合短视频片段。 做产品介绍短片分镜；从获许可的静态素材做动效草稿
10 migrate-to-codex 先盘点并预演助手配置迁移，再对照差异写入选定的 Codex 作用域。 迁移项目级助手配置；排查不能自动转换的权限项
11 doany-website-builder 在 DoAny 中提交建站或改版任务，并核对预览、草稿与发布版本。 跟踪已托管站点的改版草稿；核对首次构建的预览权限
12 ai-image-generation 用一个 CLI 比较不同的云端生图和参考图编辑工作流。 生成不含内部资料的概念图；用授权图制作多个背景变体
13 web-artifacts-builder 把带状态和多组件的 React 原型打成可分享的单个 HTML 文件。 给评审发送多视图交互原型；打包包含筛选器的数据演示
14 figma-code-connect-components 给已发布的 Figma 组件找代码库中的对应实现，核对后登记关联。 补齐设计系统的代码映射；清点同名组件的属性差异
15 ai-avatar-video 以授权肖像、脚本或配音为输入生成数字人短片，或同步已有视频口型。 用自有素材预览培训旁白；规划授权演示片段的多语言配音
16 theme-factory 从样张挑选配色与字体组合，再统一应用到幻灯片、文档或网页。 统一多作者演示稿的配色；为报告设置标题和正文字体
17 skill-installer 查看 Codex 技能目录，并按用户指定的来源安装选定技能。 区分目录中已安装与可选项；核对某个候选的仓库路径
18 academic-research 按题名、类别或日期检索预印本，并回查文献元数据与网页存档。 给学术综述建初筛文献表；核对某篇文章引用的历史网页
19 pdf-tools 仓库中的 PDF 技能测试占位，抽样未见实际 PDF 处理逻辑。 排查被名称误纳入的测试条目
20 slack-gif-creator 逐帧绘制小动画，为 Slack 表情或消息压缩 GIF 并检查输出。 制作团队内部的状态提示动画；预先检查自定义表情的大小与动效

本期推荐

9. ai-video-generation

用 inference.sh CLI 在多个云端视频模型中选择文生视频、图生视频和参考素材生成路径，也可选声音或媒体工具处理演示片段。各模型支持的输入和输出规格不同。

精选原因：按手头素材选择生成路线，比单纯罗列模型更好用；价格、画质和输出权限仍要逐项核查。skills.sh 本周记录 29,409次安装。本期仅作观察项介绍。

适用场景

  • 做产品介绍短片分镜
  • 从获许可的静态素材做动效草稿

可以这样提出任务（示意）

先根据已授权产品图拟一个短片分镜和费用估算，不提交素材。

使用前提与限制：需第三方 CLI、账号和云端额度；时长、声音、画质因模型而异，上传前核对素材与肖像权。

14. figma-code-connect-components

从 Figma 选区识别未做 Code Connect 的已发布组件，对照本地代码库的组件、属性和用例提出映射建议，再由用户选择要写入的关联。

精选原因：比对组件属性后再登记关联，适合同时维护设计库和代码库、又经常遇到同名组件的团队。本期未取得本周或累计的独立安装统计，按功能价值精选。

适用场景

  • 补齐设计系统的代码映射
  • 清点同名组件的属性差异

可以这样提出任务（示意）

对照这组已发布按钮和仓库实现列出匹配依据，暂不写回 Figma。

使用前提与限制：需 Figma MCP、可读代码与已发布组件；原文注明 Code Connect 要求组织或企业方案，写入前需确认映射。

10. migrate-to-codex

扫描已有助手的指令、技能、代理和 MCP 配置，先提出迁移计划和暂存映射，试运行后写入所选 Codex 作用域，并复核不能自动直译的权限和扩展项。

精选原因：对团队来说，先看到从哪里迁到哪里以及哪些项要手工处理，比拿到一组直接生效的配置更可控。本期未取得本周或累计的独立安装统计，按功能价值精选。

适用场景

  • 迁移项目级助手配置
  • 排查不能自动转换的权限项

可以这样提出任务（示意）

只读盘点这个仓库的助手配置，列出对应迁移位置和需要人工处理的项，不写入。

使用前提与限制：写入前核对目标作用域、现有配置、MCP 权限与钩子。不复制凭据，无法等价转换的项应手工核查。

12. ai-image-generation

通过 inference.sh CLI 选择多个图像生成模型，完成文字生图、参考图编辑或素材变体。不同接口提供不同的风格、遮罩、宽高比及参考图设置。

精选原因：要从草图做到参考图变体时，可以在同一入口换模型比较，不必先搭几套调用环境。skills.sh 本周记录 29,396次安装。

适用场景

  • 生成不含内部资料的概念图
  • 用授权图制作多个背景变体

可以这样提出任务（示意）

用已授权的产品样图比较两种背景编辑方案；先说明数据去向和预计用量。

使用前提与限制：需 inference.sh 账号与 CLI，选定模型后确认费用和使用条款，上传参考图前核对版权与数据授权。

常青回顾

13. web-artifacts-builder

为多组件交互原型初始化 React、TypeScript 和组件库工程，开发完成后用 Parcel 打包并内联脚本与样式，交付可直接分享的单个 HTML 文件。

精选原因：需要真实交互、却不想让收件人搭建前端工程时，单文件交付尤其方便。skills.sh 累计记录约 12.5万次安装，本周记录 449次安装。

适用场景

  • 给评审发送多视图交互原型
  • 打包包含筛选器的数据演示

可以这样提出任务（示意）

用虚构数据做一个可筛选的仪表盘，在独立目录里交付单文件预览。

使用前提与限制：需要 Node、pnpm 和前端构建依赖。打包脚本会安装依赖并清理旧输出，应在独立目录运行并检查分享内容。

1. reddit-automation

从指定 Reddit 社区找正在征询建议或描述具体困难的讨论，按需求清晰度、相关性和时效筛选帖子，再为合适的帖子拟写短回复。只交付草稿，发帖由人工决定。

精选原因：把少量值得参与的讨论从关键词噪声里挑出来，同时保留人工发布和利益披露这两道边界。skills.sh 累计记录约 156.3万次安装，本周记录 15,679次安装。

适用场景

  • 从指定社区寻找真实需求
  • 审核利益相关的技术回复

可以这样提出任务（示意）

读我给出的公开帖子，找哪些问题能用我的真实经历回答；只写草稿，不发帖。

使用前提与限制：需提供可读的公开帖子和真实经历。不得编造使用体验；提及自家产品时要披露关系并遵守版规，回复由人工审核、发布。
